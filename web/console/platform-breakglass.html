How Break Glass Works
The break glass key is a single emergency credential. When a system administrator is locked out and cannot use their normal recovery key, they can use the break glass master key on the password reset page to regain access.
1. Generate
Admin generates the key. The plain-text master key is shown once only — only the SHA-256 hash is stored.
2. Secure Storage
Store the key in a physical safe or offline password vault. Never share it digitally or log it anywhere.
3. Use & Revoke
After emergency use, immediately revoke this key and generate a new one. Every use is logged to the audit trail.
Security Considerations
The break glass key bypasses per-user recovery keys and grants password reset for any active account. Treat it with the same sensitivity as root or domain admin credentials.
  • Only one active break glass key exists at a time — generating a new key revokes the previous one.
  • Every use is permanently recorded in the immutable audit trail under BREAK_GLASS_PASSWORD_RESET.
  • Revoke and regenerate after each emergency use.
  • Do not store the key in any system connected to this platform.
