Complete function reference for all GRC module endpoints. All calls use POST with a JSON body containing _func.

Authentication

Auth & Request Format

All requests use POST with Content-Type: application/json. Authenticate using an API Key + Secret pair generated from Platform › API Keys in the console.

Required headers
X-API-Key: <your-api-key>
X-API-Secret: <your-api-secret>
Content-Type: application/json
Request body structure
POST /api/v1/admin/{module}

{
  "_func": "function_name",
  "param1": "value",
  "param2": "value"
}
Success response
{
  "success": true,
  // ... function-specific fields
}
Error response
{
  "success": false,
  "status": 400,
  "title": "Bad Request",
  "message": "name is required"
}

Generate API keys from the console: Platform & Access › API Keys › + Generate API Key. The secret is shown once at creation - store it securely.
