# Incidents and Awareness Guide

For IT staff and GRC (`IT_STAFF` and `GRC_OFFICER` both have write access).

## Incident Register
- Log an incident with a title, description and severity (Critical, High, Medium, Low). Status runs **New, Investigating, Contained, Resolved, Closed**.
- The schema has an escalation-rules table (role to notify and delay by severity), but no screen or service uses it yet, so severity does not trigger automatic notifications.
- The **root cause analysis** workspace records the timeline, business impact, root cause and preventative actions. Generate an RCA report from it.
- Attach documents to an incident.
- A helpdesk ticket can be escalated into an incident from IT Operations.

## Security Knowledge Base
Policies, procedures, runbooks and lessons learned for the security team, with attached documents. The knowledge base is also where you publish best practices and guidelines for staff.

## Training Campaigns
Create awareness campaigns, attach material, and enrol people. Employees complete assigned training in the [Self-Service Portal](self-service-portal-guide.md); completions are recorded.

## Note on breach reporting
Compass records and manages incidents and their RCA. It does not file reports with regulators or notify affected individuals for you.
