Discovery

Find columns that look like personal data in a database schema export, and turn them into Data Register entries you then classify and review.

‹ Data Register
Discovery proposes; people decide. You run one query on your database and upload the result (table, column and data type). Compass matches column names only: it never connects to your database and never sees or stores any data values. Nothing reaches the Data Register until you accept it. A name match is a hint, not proof, so expect some false positives and check them before accepting.

Import a schema export

1. Run the query below on your database (read-only access to information_schema is enough). 2. Save the result as CSV with a header row. 3. Upload it here. Re-importing the same source later updates findings without creating duplicates, and your accept/reject decisions are kept.
